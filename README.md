# kaidi-zha.github.io

Personal academic website for Kaidi Zha — Undergraduate Researcher in AI & Machine Learning at Tsinghua University.

Built with plain HTML, CSS, and vanilla JS. No build step, no framework.

## Sections
- Hero with links to email, GitHub, and CV
- About
- Education
- Research Experience (DiT quantization, ArchEGraph)
- Publications
- Contact
